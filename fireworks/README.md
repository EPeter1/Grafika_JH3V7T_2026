# Féléves feladat

## Cél
- Tűzijátékok modellezése: egy olyan részecskerendszer létrehozása, amely képes a tűzijátékokban gyakran látható effektek megjelenítésére
- A feladatban szereplő különböző robbanástípusokról bővebb leírás és képi anyag található az alábbi linkeken:
	- https://keystonefireworks.com/news/types-of-fireworks-effects/
	- https://www.ytmfireworks.com/firework-effects
	- https://northstarfireworks.com/fireworks-types
- A felhasznált asset-ek elérhetősége: https://drive.google.com/uc?export=download&id=1Zj0Zlnj9v6Ujx2iz6POuHC_D2IxJllRU

## Főbb elképzelések

- Legalább 8-10 db robbanástípus kidolgozása
- Fizikai rendszer szimulációja:
	- sebesség, gyorsulás
	- gravitáció
	- légellenállás
	- különböző erőhatások (pl. pörgés, csillapítás)
- Élénk színpaletta:
	- véletlenszerű színkeverés
	- izzó hatás
	- életkor alapú elhalványodás
- Dinamikusan változó csóva
